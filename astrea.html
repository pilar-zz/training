Pick today's session

🥊Strength for Muay Thai: 2 sessions per week, ~50 min each. Build muscle, develop explosive strength that carries over to the ring, strengthen glutes and protect hips, shoulders and wrists.
🧱Three layers at once: base strength (load that progresses), fast strength (moderate load moved as fast as possible) and transfer (force travelling floor → hips → torso → limb).
🔥Always warm up first (8–10 min). It is not a formality — it protects the joints Muay Thai already loads. Finish it with one light set of the day's first exercise.
⇄Equipment taken? Tap "Equipment taken" on any exercise to cycle through the alternatives.
🛑Cut-off rule: a set ends when technique degrades, not when the reps run out.

📝 Session notes

Progression

Base strength: add weight when the last rep of the last set is still clean. Slow, steady progression — no jumps.

Fast strength: don't progress by adding load, progress by keeping the speed. If the movement looks slow, take weight off.

Tabata: progress by raising intensity within the 20 seconds, not by extending the time.

Cut-off rule: a set ends when technique degrades. With Muay Thai 3x a week on top, accumulated fatigue is real — that's where injuries happen.
